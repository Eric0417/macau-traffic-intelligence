# Macao Move Build 9 verification

16 November 2026. CoreDevice installed Macao Move on the paired iPhone over the local network. A separate application query confirmed version 1.0.0, build 9. The release passed strict code signature verification. The signed package is `ios/build-device/MacaoMove-build9.ipa`, SHA-256 `89e12f624faaeebce70ef056d562e5b7d664db0e800be39969dd549f8f8c1f34`.

The stop sheet shows the stop name, arrival information, and at most one bus location. The test checks that the bus matches the estimate, the sheet has no inline map, and tapping the location opens the selected bus pin. Map perspective and the route's stop diagram remain available. The native release contains no USDZ files.

A deliberate production traffic read at 10:48:18 Macau time returned a 124-second-old cached snapshot. The next read at 10:48:19 returned a fresh snapshot. Both had 1,268 segments with 170 unknown. The direct DSAT response matched the fresh sample's status counts. A mocked transport test verifies that the native client replaces a stale snapshot on its three-second follow-up. The simulator verifies that selecting Apple traffic enables MapKit traffic and removes DSAT strokes, and that switching back disables Apple traffic. Provider coverage on individual streets and during outages is unmeasured.

The waveform animates the horizontal positions between audio meter samples. In a simulator recording, the waveform band changed on 195 successive-frame comparisons over a 3.17-second window. Most measurable moves were four device pixels left at the captured resolution. This verifies motion between meter reads in that capture. Physical frame pacing and live transcription quality were not measured.

Repository typecheck, lint and 260 tests passed. The iPhone simulator passed 46 native unit tests and five distinct UI flows across the final runs: bus positions and stop summary, stop saving, traffic source switching and assistant presentation, map perspective and send state, and voice recording with an editable fixture transcript. The first traffic UI run used the wrong accessibility element for camera state; the corrected selector passed without changes to app code. Local result bundles are `/tmp/move9-iphone.xcresult`, `/tmp/move9-map.xcresult` and `/tmp/move9-waveform.xcresult`.
