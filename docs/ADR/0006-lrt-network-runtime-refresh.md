# ADR 0006: The LRT Network Refreshes From OpenStreetMap At Runtime

## Status

Accepted

## Context

The LRT network was generated by `scripts/build-lrt-network.mjs` and imported as `data/lrt-network.json` at build time. The registry promised a 24-hour refresh, but the server re-read the same file, so a new station or line required a redeploy. MLM publishes route pages but no machine-readable topology or geometry.

OpenStreetMap carries the three Macau LRT lines as `route=light_rail` relations with member ways for geometry, stop member nodes for station order, `name:zh`, `name:en`, `name:pt` tags, and a `colour` tag per line. The checked-in file already derived its geometry and names from those relations.

## Decision

`src/server/sources/lrt-network.ts` builds the network from an Overpass payload at runtime. The LRT source tries Overpass on a cache miss and stores the result for 6 hours. Endpoints are tried in order, and `LRT_OVERPASS_URL` can point the source at a different mirror.

- Lines are grouped by relation `ref`. The relation with the most stop members wins; the lowest relation id breaks ties so stop order stays stable across directions.
- Stations are merged when their names match after dropping a trailing `站` and they are within 400 m. That is how 協和醫院 and 蓮花 become interchanges across lines.
- Stations that match the checked-in network keep the curated official name and short id. Genuinely new stations use the OSM node id and name tags. Traditional-to-simplified conversion is best effort for names the fallback does not know.
- The checked-in `data/lrt-network.json` stays as the fallback. If Overpass fails, times out, or returns fewer than 3 lines or 15 stations, the source serves the file instead.
- `npm run build:lrt` rewrites the fallback with the same builder, so the script and the runtime cannot drift.

## Consequences

- A new LRT station or line appears within 6 hours of being mapped in OpenStreetMap. No redeploy is needed.
- Overpass becomes an optional runtime dependency. An outage degrades to the checked-in network, and the cache layer retries in the background on later requests.
- New lines and stations inherit OSM naming. Known stations keep the official MLM names from the fallback.
- `timetableEdition` still refers to the official edition captured in the fallback; the UI does not display it.
