# 輕軌資料核實，2026-11-10

本輪查看 MLM 官方路線頁、官方公告 RSS、澳門開放資料相關搜尋、DSAT 公告與政府發布的澳門出行功能介紹。結果只適用於這些已查看的公開入口，不能據此斷言營運方沒有即時資料。

## 已接入的資料

[MLM 官方路線頁](https://www.mlm.com.mo/tc/route.html) 的目前服務分頁提供三線營運時間、班距與全程行車時間描述。逐站時刻表有 17 個站點／路線組合：氹仔線 13、石排灣線 2、橫琴線 2。轉乘站各線有獨立時刻表。頁面的版本註記為 2026 年 9 月。

新增 `/api/v1/lrt/service` 經 server-only adapter 和共享 cache，公開正常化文字及官方圖檔連結。2026-11-10 本機實際 API 讀取成功，三條線及 17 個連結通過解析。6 小時刷新，來源失敗可保留一天的舊資料並標示延遲。

同一 HTML 仍保留 2020 年疫情期間班距內容。Parser 只讀目前服務和時刻表分頁，不全文搜尋「班次安排」。Fixture 包含舊內容並驗證不會混入。

## 即時資料的界線

官方時刻表是 JPG 圖片，列出計劃出發時間。這次直接連到原圖，沒有 OCR 後自行宣稱下一班到站倒數。地圖的列車仍是示意動畫。

[DSAT 的澳門出行 2.0 公告](https://www.gcs.gov.mo/news/detail/zh-hant/N24FaUGiE0) 描述整合交通資訊與消息功能，但不是公開輕軌即時 API 契約。[DSAT 發布的應用程式介紹](https://play.google.com/store/apps/details?hl=zh_TW&id=mo.gov.dsat.dis.travel) 可作功能入口查考，亦不能單靠功能介紹確立對外 API 的欄位、更新時間及使用條件。

本次沒有核實到可直接接入的公開輕軌位置／到站接口。下一步要取得 MLM／DSAT 的公開規格或正式資料許可，並核對真實回應中的站點、方向、來源時間及失效狀態後再接入。使用既有官方公開查詢入口不需要把未核實的分鐘數加到產品。

## 驗證範圍

Parser 測試使用已讀取頁面的服務區塊 fixture，不連政府服務；涵蓋三線與 17 份表、舊區塊排除、版面失效與外部 URL 拒絕。端到端測試 mock API，驗證時刻表連結及計劃資料標示。沒有聲稱已驗證每一班實際運行時間。
